# Guide first-time Agent connections

Date: 2026-11-22

## Summary

Invited workspace members can set up their first Passkey and follow the Muse pairing steps from Agent management.

## Changes

- Show Passkey setup for a new account and keep the usual unlock prompt for existing accounts.
- Provide a copyable message for Muse and ChatGPT in the current workspace language. Use the configured Foliocrew MCP address and include the public Client ID for Muse on that address.

## Validation

- Exercise first-use Passkey setup and the localized connection messages, including the copied text and a deployment without the branded address.
