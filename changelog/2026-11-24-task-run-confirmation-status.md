# Distinguish saved task schedules from confirmed runs

Date: 2026-11-24

## Summary

The Task Center shows saved schedule settings separately from Agent confirmation and manual run requests.

## Changes

- Show a pending schedule confirmation without predicting an upcoming run. Label an upcoming
  time from an Agent-reported plan as a calendar preview.
- Label manual actions as run requests and explain when the selected Agent can pick them up.

## Validation

- Verify scheduled and unconfirmed task states and run controls in all three workspace locales.
